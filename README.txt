DUST ENERGY — FIKCYJNY ARTYKUŁ / MAKIETA STUDENCKA

Jest to oryginalna makieta strony z artykułem w stylistyce dużego portalu informacyjnego.
NIE jest stroną Onet.pl ani prawdziwą publikacją Onetu.

Pliki:
- index.html — strona główna artykułu
- assets/ — zdjęcia i wizualizacje projektu

Publikacja na GitHub Pages:
1. Stwórz publiczne repozytorium, np. dust-artykul.
2. Prześlij index.html oraz folder assets/ bezpośrednio do katalogu głównego repozytorium.
3. Settings → Pages → Build and deployment: Deploy from a branch → main → /(root) → Save.
4. Otwórz URL w formie https://TWOJ-LOGIN.github.io/dust-artykul/.

Możesz również otworzyć index.html lokalnie (strona działa także bez połączenia z Internetem;
przy braku internetu zdjęcie główne automatycznie zostanie zastąpione grafiką DUST).

Źródła naukowe są podlinkowane w sekcji Źródła na dole artykułu.
Koncept DUST ENERGY: fikcyjna marka; skład i właściwości nie są potwierdzone badaniami produktu.

Dopasowanie:
Możesz swobodnie zmienić datę, treść i elementy wizualne na potrzeby prezentacji.
Zalecamy zachować oznaczenie, że jest to makieta, a nie prawdziwa publikacja Onetu.
